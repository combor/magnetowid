VOD downloads for Sonarr and Radarr

magnetowid brings video-on-demand sites to Sonarr and Radarr. Search for a series or a film as you always do, and it arrives in your library as an MP4 file, with subtitles.

Get it on GitHub Quick start Free and open source

Supported sites

To your apps, magnetowid is an ordinary indexer and download client: a Newznab indexer for each site, and a SABnzbd-compatible client that does the downloading itself. No separate SABnzbd installation is needed.

  • TVP VOD /tvp Polish series and films. Streams may need a Polish connection.
  • BBC iPlayer /bbc Streams need a UK connection.

Only what a site offers for free is found: DRM-protected, paid and region-blocked streams are left out of the results. To use a site from another country, give it a VPN exit: see Region-locked sites.

What you get

  • Search and RSS

    Sonarr and Radarr search each site and pick up new episodes and newly available films on their own.

  • Releases named like any other

    Names carry the resolution, codecs and audio language, so your quality and language profiles keep working.

  • Subtitles

    Saved beside the video as SRT, labelled with their language.

  • Downloads that pick up where they stopped

    Pause one, restart magnetowid or lose the connection, and it continues from the last segment.

  • A web interface

    Watch the queue, pause and remove downloads, and browse the history.

  • Overrides

    When a title is missed or episodes are paired wrongly, correct the match yourself.

Quick start

  1. Get the configuration

    You need Docker with Compose. The container image includes ffmpeg.

    mkdir magnetowid
cd magnetowid
curl -fsSLO https://raw.githubusercontent.com/combor/magnetowid/main/compose.yaml
curl -fsSL https://raw.githubusercontent.com/combor/magnetowid/main/.env.example -o .env
mkdir -p downloads

  2. Edit .env

    Set MAGNETOWID_API_KEY to a long, random key; Sonarr and Radarr use the same one. Point MAGNETOWID_DOWNLOAD_PATH at your shared download folder, or keep ./downloads.

  3. Start magnetowid

    docker compose up -d

    Everything is served on port 8484.

  4. Connect Sonarr and Radarr

    Open http://<magnetowid-host>:8484/, sign in with the API key and go to Setup. It lists what to add in each app: a SABnzbd download client and a Newznab indexer for each site. Step-by-step guide.

Not using Docker? Install the Linux service from the magnetowid-bin AUR package or the .deb and .rpm packages on the releases page, or build from source.
